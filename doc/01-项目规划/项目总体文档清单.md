## 二、现有文档摘要

### 2.1 项目原型分析文档

**文件路径**：`/doc/01-项目规划/项目原型分析文档.md`

**核心内容**：
- 项目背景与目标：合江汉代画像石棺数字化保护与展示
- 技术栈分析：原型使用HTML/CSS/JS ES5 + model-viewer + Pannellum
- 功能模块：游客端6个页面 + 管理后台19个页面
- 数据规模：13处崖墓群、28具石棺、多类型成果图
- 当前局限性：纯静态、无后端、无数据库

**文档目的**：为后续开发提供基线参考

---

### 2.2 技术架构深度分析报告

**文件路径**：`/doc/03-系统设计/技术架构深度分析报告.md`

**核心内容**：
- 前端架构：Vue3 + TypeScript + Vite + 组件库
- 后端架构：Spring Boot 3.2+ / NestJS + MySQL + Redis
- 状态管理：Pinia全局状态 + 组件级状态
- 样式系统：CSS变量 + Sass/Less + 国风主题定制
- 演进路线：从原型到生产的架构迁移方案

**文档目的**：指导技术选型与架构设计决策
